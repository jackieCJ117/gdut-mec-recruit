关于机创 ABOUT

MODULE 02/09 · DATA.SYNC

一支把课堂变成图纸、把图纸变成机器的学生科创团队。

机械创新团队（Mechanical Innovation Team，简称「机创」）是广东工业大学的学生科创团队，以机械设计为根、以电控与视觉识别为翼，围绕机器人、智能装备与创新课题展开学习与实践。

在这里，你能接触到从三维建模、单片机控制到视觉算法、品牌运营的全链路技能；也能和一群愿意为作品熬夜、为调试较真、为比赛拼尽全力的伙伴并肩。

成长路径 GROWTH PATH
  1. 01
    基础培训组内每周培训，从建模 / 编程 / 算法入门。
  2. 02
    分组实战进入对应组别，在真实任务中练手。
  3. 03
    项目打磨参与整车项目，学长全程把关带练。
  4. 04
    赛事检验代表团队出战，让作品接受赛场检验。

C 语言高阶编程与架构

  • 核心语法深耕 系统学习 C 语言，重点攻克指针操作与内存管理，打下坚实的底层代码基础。

  • STM32 开发实战 熟练掌握 STM32 微控制器及其 HAL 库的使用，能够驱动各类常用外设传感器与执行器。

  • PID 控制算法 深入学习经典的 PID 算法，掌握速度闭环与位置闭环控制策略，实现对电机等执行机构的精准控制。
